01 / COMPUTER NETWORKING

praktik crimping kabel jaringan

Praktik dasar penyambungan kabel jaringan menggunakan konektor RJ45 untuk membangun konektivitas ant perangkat. Kegiatan ini melatih ketelitian dalam menyusun kabel serta memahami fungsi kabel jaringan dalam proses komunikasi data.

activities

  • Mengenal jenis dan fungsi kabel jaringan.
  • Mempelajari susunan kabel straight dan crossover.
  • Memasang konektor RJ45 sesuai kebutuhan praktik.
  • Memeriksa hasil crimping dan menguji koneksi kabel.

skills: cable crimping, network cabling, troubleshooting dasar, dan ketelitian.

02 / NETWORK CONFIGURATION

konfigurasi dan troubleshooting jaringan

Kegiatan pembelajaran untuk memahami pengaturan jaringan komputer dan proses identifikasi gangguan koneksi. Melalui praktik ini, saya belajar menganalisis masalah serta memahami langkah penyelesaian kendala jaringan.

activities

  • Mempelajari alamat IP dan subnet mask.
  • Memahami konfigurasi jaringan antarperangkat.
  • Mengenali masalah konflik alamat IP.
  • Mempelajari pengecekan dan penanganan gangguan koneksi.

skills: IP addressing, network configuration, problem-solving, dan troubleshooting.

03 / FIBER OPTIC NETWORKING

pembelajaran fiber optik

Pembelajaran mengenai teknologi fiber optik sebagai media transmisi data yang menggunakan cahaya. Materi ini membantu saya memahami karakteristik fiber optik dan perhitungan teknis yang berkaitan dengan penggunaannya.

activities

  • Mengenal fungsi dan karakteristik kabel fiber optik.
  • Mempelajari perhitungan yang berkaitan dengan kabel fiber optik.
  • Memahami peran fiber optik dalam jaringan komunikasi.

skills: pemahaman media transmisi, perhitungan teknis, dan analisis dasar.

04 / NETWORK INFRASTRUCTURE

pengenalan infrastruktur jaringan

Pengalaman pembelajaran untuk mengenal infrastruktur telekomunikasi dan peran perangkat pendukung dalam sistem jaringan. Kegiatan ini memberikan wawasan mengenai lingkungan kerja bidang jaringan serta pentingnya keselamatan kerja.

activities

  • Mengenal fungsi infrastruktur telekomunikasi.
  • Memahami peran menara dalam sistem komunikasi.
  • Mempelajari pentingnya prosedur keselamatan dalam kegiatan praktik.

skills: pemahaman infrastruktur, kedisiplinan, dan kesadaran keselamatan kerja.

05 / SERVER ADMINISTRATION

pembelajaran server dan jaringan

Pembelajaran mengenai fungsi server sebagai penyedia layanan dan sumber daya dalam jaringan komputer. Materi ini menjadi bagian dari pengenalan sistem jaringan yang mendukung komunikasi serta pertukaran data antarperangkat.

activities

  • Mengenal fungsi dan jenis server.
  • Memahami hubungan server dengan client.
  • Mempelajari konsep layanan jaringan sesuai materi praktik.

skills: dasar administrasi server, pemahaman client-server, dan analisis sistem.
