✦ WEB DEVELOPMENT / HTML & CSS

Website Portofolio Pribadi (Pink Digital Diary)

Proyek pembuatan website portofolio interaktif berbasis HTML, CSS, dan JavaScript dengan tema estetika digital diary.

Hal yang Dipelajari & Dikerjakan:

  • Menyusun struktur halaman web yang rapi menggunakan HTML5 semantik.
  • Mendesain tata letak responsif menggunakan CSS Grid dan Flexbox.
  • Menambahkan sentuhan visual menarik dengan efek CSS gradient dan SVG kustom.
SKILLS: HTML5 • CSS3 • Responsive Web Design • UI Styling
✦ NETWORKING / CISCO PACKET TRACER

Simulasi Topologi Jaringan LAN & Routing Dasar

Dokumentasi praktikum konfigurasi jaringan komputer menggunakan Cisco Packet Tracer untuk menghubungkan beberapa antardepartemen.

Hal yang Dipelajari & Dikerjakan:

  • Merancang skema pengalamatan IP (IPv4 Subnetting).
  • Konfigurasi dasar Switch dan Router (VLAN & Inter-VLAN Routing).
  • Melakukan pengujian konektivitas antarnode menggunakan perintah ping dan traceroute.
SKILLS: Cisco Packet Tracer • Subnetting • VLAN • Routing Dasar
✦ CYBERSECURITY / NETWORK SECURITY NOTES

Catatan Belajar & Eksplorasi Dasar Keamanan Siber

Kumpulan studi literatur dan eksperimen mandiri mengenai prinsip dasar keamanan informasi, ancaman siber, dan cara mengamankan sistem jaringan.

Fokus Topik Pembelajaran:

  • Pemahaman tentang konsep CIA Triad (Confidentiality, Integrity, Availability).
  • Pengenalan jenis-jenis serangan umum (Phishing, Malware, Man-in-the-Middle).
  • Latihan pemindaian port dasar menggunakan tools seperti Nmap pada lingkungan lab privat.
  • Prinsip dasar pengamanan Wi-Fi dan penggunaan password manager.
"Keamanan siber bukan tentang membuat sistem yang 100% tidak bisa ditembus, melainkan memahami risiko dan membangun pertahanan yang lebih baik secara berkelanjutan."
SKILLS: Network Security Basics • Cyber Threat Fundamentals • Nmap Basics • System Hardening Concept
